# Fictional demo portraits

The eight PNG portraits were generated with OpenAI image generation on 2026-11-03 specifically for this project. The prompts requested fictional adults, professional business-casual headshots, plain neutral backgrounds, and no text or logos. No reference photograph of a real person was supplied.

Files: alex.png, sam.png, jamie.png, priya.png, daniel.png, noor.png, leo.png, elena.png. Each file was visually inspected after generation. The generated originals are preserved outside the repository; these copies ship as local SPFx assets. There is no runtime dependency on an external image host.

Names, professional summaries and identities are fictional. Each person may have records for different skills; there are no repeated people within a single skill result set. These are illustrative demo profiles, not employees or tenant users. Generated assets are provided with this demo under the repository license; no third-party stock photographs were used.
